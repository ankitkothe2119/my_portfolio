# Ankit Kothe – Portfolio (Next.js)

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Edit content

All content lives in `app/page.js`: `projects`, `experience`, `skills`, and `links`.

## Deploy

Push the folder to GitHub, then import it on Vercel (vercel.com/new). No configuration is needed.
